Source of [lab.solgaard.uk](https://lab.solgaard.uk): my Home Assistant and Zigbee projects, and device reviews.

Plain static HTML, served by GitHub Pages from `main` (custom domain in `CNAME`). To add a review, copy a `<li class="review">` block in `index.html`, change the name, type and link, and push.
